# Воинский учёт — рабочий контур

Локальное веб-приложение для одного специалиста по ведению воинского учёта.
Карточки сотрудников, задачи и настройки сохраняются в `localStorage` браузера
и не отправляются на сервер.

## Возможности

- импорт сотрудников из Excel;
- поиск, сортировка и фильтрация реестра;
- карточки сотрудников и контроль обязательных полей;
- задачи по приёму, увольнению, изменениям сведений, запросам и сверкам;
- подготовка Формы № 10 строго на двух страницах A4;
- подготовка одностраничной Справки Ф-2;
- выгрузка настоящих редактируемых файлов DOCX;
- формирование заполненных редактируемых документов Word: Формы № 10, справки Ф-2 и «Листка сообщений»;
- связь документов с задачами: после отметки документа отправленным соответствующая задача закрывается автоматически;
- единые дата отправки и исходящий номер в истории документов и уведомлений;
- автоматический рабочий план на выбранный месяц со статусами задач и связанных документов;
- выгрузка рабочего плана в Excel с фильтрами и исходящими номерами;
- диагностика базы: связи, возможные дубли, полнота карточек, сроки, звания и резервные копии;
- итоговый контрольный отчёт Excel с отдельными листами по карточкам, задачам и найденным замечаниям;
- встроенные резервные шаблоны списков офицеров и рядовых для надёжной выгрузки на GitHub Pages;
- одностраничный «Листок сообщений» с корешком и автозаполнением по предоставленному шаблону;
- резервное копирование и восстановление локальной базы.

## Запуск

Требуется Node.js версии `22.13` или новее.

```bash
npm install
npm run dev
```

После запуска откройте адрес, который будет указан в терминале.

Проверка production-сборки:

```bash
npm run build
```

## Публикация через GitHub Pages

Проект настроен для репозитория `military-registration`.

1. Загрузите в корень репозитория всё содержимое архива, включая скрытую
   папку `.github`.
2. В GitHub откройте `Settings → Pages`.
3. В поле `Source` выберите `GitHub Actions`.
4. После загрузки файлов дождитесь завершения процесса
   `Deploy to GitHub Pages` во вкладке `Actions`.

Команда `npm run build:github` формирует статический сайт в папке `out` и
учитывает адрес `/military-registration`.

## Начало работы

1. Откройте раздел «Настройки» и заполните данные организации.
2. Импортируйте Excel либо создайте карточки вручную.
3. Проверьте фильтр «Есть пропуски».
4. Создавайте события — программа рассчитает контрольные сроки.
5. Регулярно создавайте резервную копию в разделе «Настройки».

## Хранение и безопасность

- В приложении нет отдельного логина: оно рассчитано на одного пользователя и
  одно защищённое рабочее устройство.
- Данные одного браузера не появятся автоматически в другом браузере или на
  другом компьютере.
- Очистка данных браузера удалит локальную базу, если заранее не сделать
  резервную копию.
- Исходный код и архив не содержат реестр сотрудников из тестового Excel.

## Основные файлы

- `app/page.tsx` — интерфейс, импорт, карточки, сроки и документы;
- `app/globals.css` — стили интерфейса;
- `public/documents/` — редактируемые Word-шаблоны Формы № 10 и справки Ф-2;
- `.github/workflows/deploy-pages.yml` — автоматическая публикация GitHub Pages;
- `package.json` — команды и зависимости проекта.
